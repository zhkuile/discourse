# 云顶论坛站点设置清单

本文档用于指导将当前 Discourse 项目配置为“云顶论坛”，重点覆盖品牌替换、基础展示、导航体验、通知邮件和社区初始化所需的关键设置。

## 1. 使用说明

建议按以下顺序进行设置：

1. 先完成品牌基础信息
2. 再完成 Logo / 图标 / 分享图设置
3. 再调整首页与导航相关配置
4. 最后处理邮件、法律、社区运营相关设置

## 2. 品牌基础信息

这些设置最优先，决定论坛是否仍然呈现默认 Discourse 品牌感。

### 必改项

- `title`
  - 建议值：`云顶论坛`
- `site_description`
  - 建议值：`面向大数据、人工智能、Web3 及延展话题的专业社区`
- `short_site_description`
  - 建议值：`聚焦技术、连接观点、分享实践`
- `company_name`
  - 建议值：`@ydstack`
- `contact_email`
  - 建议值：使用你的官方联系邮箱
- `contact_url`
  - 建议值：云顶论坛官网或联系页链接
- `notification_email`
  - 建议值：如 `noreply@your-domain.com`
- `site_contact_username`
  - 建议值：`ydstack` 或官方管理员账号
- `site_contact_group_name`
  - 建议值：官方管理组名称

### 建议补充项

- `governing_law`
  - 按实际法务主体填写
- `city_for_disputes`
  - 按实际城市填写

## 3. 品牌资产与图标

这些设置用于彻底替换默认站点图形识别。

### 必改项

- `logo`
  - 云顶论坛主 Logo
- `logo_small`
  - 云顶论坛小尺寸 Logo
- `mobile_logo`
  - 移动端 Logo
- `logo_dark`
  - 深色模式主 Logo
- `logo_small_dark`
  - 深色模式小 Logo
- `mobile_logo_dark`
  - 深色模式移动端 Logo
- `digest_logo`
  - 邮件摘要 Logo
- `favicon`
  - 浏览器图标
- `apple_touch_icon`
  - iOS 添加到主屏图标
- `opengraph_image`
  - 社交分享图
- `manifest_icon`
  - PWA 图标
- `large_icon`
  - 大图标资源

### 建议说明

建议准备一套统一风格的资产包：

- 主 Logo
- 暗色 Logo
- 简化 Logo
- Favicon
- 分享卡片图
- 邮件 Logo
- 手机图标

## 4. 语言与本地化

你的论坛主要面向中文用户，建议优先设置中文体验。

### 推荐项

- 默认语言设为 `zh_CN`
- `allow_user_locale`
  - 建议保留开启，允许用户自行切换语言
- `set_locale_from_accept_language_header`
  - 可按需要开启
- `set_locale_from_cookie`
  - 建议开启

### 文案覆盖建议

除了站点设置，还应通过“自定义文本”或主题国际化覆盖以下内容：

- About 页标题和说明
- 登录/注册页欢迎文案
- 页脚说明
- 系统欢迎提示
- 某些用户可见的默认 Discourse 文案

## 5. 首页与导航相关设置

虽然 Discourse 的很多导航效果依赖主题和分类配置，但以下设置仍然需要配合调整。

### 推荐项

- 首页默认显示建议根据社区目标确定：
  - 推荐优先：`categories` 或 `latest`
- 顶部导航建议控制在核心项范围内
- 开启分类展示、标签展示与边栏导航能力

### 配套动作

这些不是单独 setting，但必须同时完成：

- 创建一级分类：大数据、人工智能、Web3、人文、地理、云顶产品、社区公告、新手专区
- 创建标签：安装部署、问题求助、使用教程、资源分享、功能建议、活动公告、版本更新等
- 设置默认置顶主题：论坛指南、新手必读、发帖规范、产品导航

## 6. 关于页与社区说明

这些内容虽然很多来自文本和主题配置，但站点设置层要先准备好基础信息。

### 建议内容方向

- 云顶论坛是什么
- 社区覆盖哪些方向
- 社区由谁运营：`@ydstack`
- 社区规则与价值观
- 联系方式与合作方式

### 相关设置建议

- 站点描述与扩展描述应统一使用云顶论坛品牌语言
- 如启用 About Banner，建议使用品牌化横幅

## 7. 邮件与通知设置

邮件是最容易暴露默认品牌的地方，必须认真处理。

### 必改项

- `notification_email`
- `digest_logo`
- 邮件发件人显示名称
- 邮件标题前缀
- 欢迎邮件文案
- 忘记密码邮件文案
- Digest 邮件文案

### 建议目标

确保用户收到的每一封邮件都只感知到：

- 云顶论坛
- @ydstack
- 官方域名
- 官方联系邮箱

## 8. SEO 与分享设置

要让论坛在外部传播时也体现云顶论坛品牌。

### 必改项

- `title`
- `site_description`
- `short_site_description`
- `opengraph_image`
- 品牌域名与 canonical 配置

### 建议目标

当论坛页面被分享到微信、X、Telegram、Slack 或搜索引擎收录时，展示应为：

- 云顶论坛名称
- 云顶论坛描述
- 云顶论坛品牌图

## 9. 用户体验与社区运营设置

以下不一定全是品牌设置，但会显著影响论坛的“专业感”。

### 推荐调整方向

- 新用户引导更友好
- 允许用户自定义边栏
- 分类与标签组织清晰
- 合理设置发帖、回复、编辑权限
- 启用解决方案、标签跟踪、分类关注等能力

### 推荐同时启用或确认的能力

- 标签体系
- 分类关注
- 已解决方案机制
- 公告 / 置顶机制
- 搜索体验优化
- 官方账号识别

## 10. 去 Discourse 化检查清单

以下内容需要逐项排查：

- [ ] 站点名称是否仍显示 Discourse
- [ ] favicon 是否仍是默认图标
- [ ] 邮件是否仍显示 Discourse 默认品牌
- [ ] About 页是否暴露默认版本/品牌信息
- [ ] 分享卡片是否仍使用默认资源
- [ ] 登录页/注册页是否仍有默认品牌语气
- [ ] 页脚或帮助页是否保留默认品牌信息

## 11. 上线前建议确认

上线前建议进行一次品牌巡检：

- 桌面端首页
- 移动端首页
- 登录页
- 注册页
- About 页
- FAQ / 条款 / 隐私页
- 邮件通知
- 社交分享卡片
- 搜索引擎预览信息

## 12. 推荐的建议值总表

### 品牌必填

- 站点名：`云顶论坛`
- 所有权/运营主体：`@ydstack`
- 站点描述：`面向大数据、人工智能、Web3 及延展话题的专业社区`
- 短描述：`聚焦技术、连接观点、分享实践`

### 联系方式

- 联系邮箱：官方邮箱
- 通知邮箱：品牌域名邮箱
- 官方联系人：`ydstack`

### 图形资产

- 主 Logo：云顶论坛品牌 Logo
- 暗色 Logo：对应暗色版本
- Favicon：云顶品牌图标
- 分享图：云顶论坛 OG 图
- 邮件 Logo：云顶论坛邮件头图

## 13. 实施建议

建议将这份清单与以下文档配合使用：

- `docs/yunding-branding-plan.md`
- `docs/yunding-information-architecture.md`

先完成站点设置，再做信息架构和主题化改造，最后做少量源码覆盖，这样实施成本最低、效果最好。
